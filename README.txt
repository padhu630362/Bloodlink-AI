# Intelligent Blood Emergency Response System — RaktaSetu-style prototype

This is an ORIGINAL student prototype with a visual structure and workflow inspired by publicly visible blood-network platforms. It does not copy proprietary code, branding, images, or exact page design.

## Included
- Blood availability search
- Donor registration
- Emergency blood request
- Inventory dashboard
- AI-assisted donor matching demonstration
- Local RAG knowledge assistant
- SQLite database
- FastAPI backend + single-page frontend
- Windows one-click START_APP.bat

## Requirements
Python 3.10+ on Windows. Node.js is NOT required.

## Start
Double-click START_APP.bat.

The first run creates a local virtual environment and installs packages. The browser opens at:
http://127.0.0.1:8000

Keep the black server window open while using the application.

## Important
This is an educational prototype. Demo data is synthetic/local. AI matching and blood information are not medical advice and must not be used for real transfusion or donor-eligibility decisions. Real deployment requires verified blood-bank data, qualified medical oversight, authentication, security, privacy, regulatory compliance, real-time integrations and clinical validation.
